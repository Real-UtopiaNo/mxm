`Pet_Loadout_20261108_001150_614920` 的无损失败画面原样保存在
`tests/fixtures/pet_loadouts/town_daily_badge_20261108.png`。零点重启后家族盾牌右上
出现每日任务感叹号，使旧场景模板相关性降到 `.882823`，低于 `.92`，而宠物猫头
图标仍是完整匹配 `1.0`；因此整个等待过程未发出点击。新的 `town_page.png` 来自
原 `town.png` 以 `INTER_AREA` 归一至 960×540 后的 `[590,103,620,133]`，
只取眼睛内侧与左侧紫色轮廓，避开右上方会被云覆盖的外围。搜索范围为
`[584,97,626,139]`，相关性要求提高至 `.94`，像素误差上限收紧为 `12`，
避免这块较暗的场景图案在弹窗下仅剩 85% / 80% 亮度时仍被误认。
新锚点在本次原始 PNG 上为 `.99967`；覆盖七张真实主城画面的六种尺寸回放。
回城与屠龙使用同一内侧范围在各自参考尺寸下裁剪，防止几套场景识别不一致。
完整回放使用本次真实主城作为起点和终点，验证三组均能打开宠物页、选择组名、
应用、确认并回城；家族图标被覆盖时仍可由红眼确认主城。
