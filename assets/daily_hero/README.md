# Daily_Hero 视觉素材

PNG 均裁自本机雷电模拟器的真实 1920×1080 截图。`profile.json` 描述模板文件、搜索范围、相关性阈值和允许的平均像素差。

`region_*` 包含区域名称和推荐等级。`marker_search_offset` 是相对匹配到的区域标签的标记搜索范围；必须同时检测到 `world_marker` 才算候选区域。当前区域的红色菱形定位标志不属于感叹号。

区域可配置 `click_offset: [dx, dy]`，相对于区域模板匹配中心、单位为 1920×1080 参考像素；省略时点击匹配中心。奇幻梦境、异界幻世的推荐等级不在有效点击区域，因此使用 `[0, -60]` 点击上方图标。实际运行、补点和预演共用这个偏移，补点前仍重新定位模板。

`marker` 用于区域内副本标签右端的小感叹号，只保留图标内部，避免周围地图颜色影响匹配；搜索范围包括最右侧的陨落通道。点击位置是标记匹配中心向标签内部偏移，随后必须匹配副本面板才能继续。

`obscured_markers` 为聊天预览遮住的标记提供补充识别。弗瑞斯先匹配同一区域中稳定可见的神秘林名牌，再检查相对位置上的小范围是否仍有足够的橙色标记像素。两者同时成立才算未完成，不会仅凭副本位置重复挑战；完整图标与遮挡识别结果按位置去重。聊天预览不会拦截名牌点击。

当前区域的红色菱形优先使用模板识别；背景或发光效果导致模板不匹配时，使用红色和细长菱形轮廓补充识别，避免被定位标志遮住感叹号的整个区域被跳过。
目标已经是当前区域时，关闭大地图返回该区域，不重复点击无响应的同一区域标签。

按钮识别除相关性外，还比较彩色像素，避免把黄色“下一关”与灰色禁用按钮、弹窗下变暗的背景按钮混淆。`victory` 和 `defeat` 使用顶部大标题，避免把敌方头像上的“失败”误判为玩家失败。

`moru_midpoint.png` 取自 `Daily_Hero_20261106_010424_859874/completed_12.jpg` 的敌方硬甲蛹名称、等级3和头像组合，作为莫鲁之地第三怪中场出口的识别锚点。它必须与胜利、灰色“下一关”和“退出战斗”同时使用，不是整本通关凭证。退出后继续核验原副本是否还有“挑战”，再打第四、第五怪；这样即使本次运行从已有前两怪进度开始，也不会把第三怪退出误计为完成。此截图在测试中改记为 `west_three_stage_complete.jpg` 的历史文件名，实际表示中场，不表示全关卡完成。

普通模式龙图标的金色高光会变化：已有普通面板与已通关的哈尔雪山面板形状相关度均高于0.97，但后者的平均颜色误差约30.29。因此仅 `normal_dragon.max_error` 设为35，保留原相关度阈值与搜索框。英雄脚本和重置脚本在首次点击及补点前还要求同帧能识别 `panel_close`，排除弹窗暗化的背景图标。

新增/替换素材后，运行截图回放测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

真实截图回放样本保存在 `tests/fixtures/daily_hero/`；运行现场和匹配日志保存在已忽略的 `artifacts/` 下。
